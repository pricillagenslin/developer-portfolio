# React Developer Portfolio

Vite + React + TypeScript + MUI + Redux Toolkit + Framer Motion + React Router.

    npm install
    npm run dev       # local dev
    npm run build     # type-check and production build

## Make it yours
All content lives in `src/data/` (profile, skills, experience, education, projects, services). Search for `TODO` and `[ADD` to find placeholders. Add a screenshot to `public/` and set `image` on a project; drop your résumé at `public/resume.pdf`.

## Structure
- `components/ui` reusable primitives (motion, Reveal/Stagger, Section, Counter, TechChips)
- `components/layout` Navbar, Footer, SocialLinks
- `components/sections` one component per section, plus ProjectCard
- `store` Redux, used only for theme mode
- `theme` MUI light/dark theme factory
